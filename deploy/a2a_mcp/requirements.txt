# Major versions are capped because this server is built from an unpinned
# rebuild each time, and a new major can remove APIs it imports. That is not
# hypothetical: mcp 2.0.0 dropped `mcp.server.fastmcp` (used at a2a-mcp.py:59)
# and crash-looped the container on the next `docker compose build`.
#
# Verified working set (server boots, /healthz, REST, /mcp/ mount, CLI):
#   mcp 1.29.0, uvicorn 0.52.1, starlette 1.3.1
#
# Moving to mcp 2.x needs a code port, not a version bump — see the FastMCP
# usage around a2a-mcp.py:59 and the /mcp mount in build_app().
mcp>=1.27,<2
uvicorn<1
starlette<2
# The MariaDB driver. PyMySQL on purpose rather than mariadb/mysqlclient: it is
# pure Python, so the image needs no compiler and no libmariadb headers, which
# is the same reason the rest of this list is three lines long.
pymysql>=1.1,<2
